## Publish on GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `sir-emmanuel-comptech`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the `main` branch and `/ (root)`, then Save.
7. Wait for the Pages deployment. Your site will receive a `github.io` address.
8. For a custom domain, purchase an available `.co.ke` domain and configure it under Settings > Pages > Custom domain, then follow the DNS instructions GitHub provides.

## Notes
The contact form intentionally opens WhatsApp instead of requiring a server. This makes the static website easy to host.
